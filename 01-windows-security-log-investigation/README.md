# Project 01: Windows Security Log Investigation

## Objective

Investigate Windows security events to understand authentication activity, identify potentially suspicious patterns, and document evidence-based findings.

## Scenario

A security analyst has been asked to review authentication events on a Windows workstation following concerns about unusual login activity.

The task is to determine what the available event records show, whether further investigation is justified, and what defensive actions may be appropriate.

**Scenario type:** Training investigation  
**Evidence status:** Not yet collected  
**Incident status:** Undetermined

## Investigation Tasks

1. Identify relevant Windows Security events.
2. Collect suitable event records from an authorised source.
3. Examine timestamps, account names, logon types, and source information where available.
4. Identify patterns that warrant further investigation.
5. Build an evidence-based event timeline.
6. Document findings, limitations, and recommendations.

## Key Event IDs

| Event ID | Description |
|---|---|
| 4624 | Successful logon |
| 4625 | Failed logon |
| 4634 | Logoff |

These events must be interpreted in context. A failed logon alone does not prove an attack.
